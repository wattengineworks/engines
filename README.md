# Watt Engineworks — Engines

Free, self-hosted AI engines, built live on stream, running on hardware you own.

An **engine** is everything an AI needs to do one part of your life for you: the model, the tools it can use, the skills, the code. Each episode ships one working **part** of an engine. Everything here is free to use and free to change.

## How to use a part
Each episode folder has a `README.md` with the build steps, the config files it needs, and `prompts.md` with every prompt verbatim. Versions are pinned to what was shown on stream; use the release tag for the episode (`ep00`, `ep01`, …) to get exactly that.
